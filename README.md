# 🎯 Guess The Number Game

A simple command-line number guessing game built with Python.

## Features

- 🎲 Random number generation
- 🔁 Unlimited guessing attempts
- 📈 "Too High" and "Too Low" hints
- 🔢 Counts total attempts
- 🚪 Type `Quit` to exit the game anytime
- ⚠️ Handles invalid input using `try` and `except`

## Technologies Used

- Python 3
- random module

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run:

```bash
python guess_the_number.py
```

## How to Play

- Guess a number between **1 and 100**.
- If your guess is incorrect, you'll get a hint:
  - Too High
  - Too Low
- Type **Quit** to exit the game.
- The game displays the total number of attempts after a correct guess.

## Sample Output

```
Guess Number (1,100) or Quit: 60
Too High

Guess Number (1,100) or Quit: 30
Too Low

Guess Number (1,100) or Quit: 42
Correct, It is 42
You guessed it in 3 attempts
```
